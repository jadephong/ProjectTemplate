# Agents

将项目所需的 AI agents 配置放在这里。

参考：[jadephong/agency-agents-zh](https://github.com/jadephong/agency-agents-zh)

## Agent 类型

- **Frontend Agent**: 前端开发
- **Backend Agent**: 后端开发
- **DB Agent**: 数据库设计
- **DevOps Agent**: 基础设施
- **Review Agent**: 代码审查
- **Git Agent**: Git 工作流
- **Product Agent**: 产品策略

## 使用方式

在 Claude Code 中使用对应 agent 处理任务。
